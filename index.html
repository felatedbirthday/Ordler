Ordler

Points are awarded each day based on who solves their puzzle in the fewest guesses. Wordle winners earn 1 point, Quordle winners earn 2 points, and Octordle winners earn 3 points. A bust (failure to solve) costs −1 point. Tied players split the available points.

Remote Sync Settings

If you'd like to synchronise scores across devices, you can enable remote syncing via GitHub. The scoreboard data will be stored in scoreboard.json in this repository. You only need to provide a GitHub personal access token with "repo" scope once per device. Leaving these fields blank will still load the remote scoreboard but will not write updates back to GitHub.
